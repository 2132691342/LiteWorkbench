# 13 · 提示词库

## 定位

提示词是创作的复用单元：把反复使用的指令固化成模板，变量化后一键渲染。

边界：本模块管模板存储与变量渲染，不负责把结果送进会话（由前端决定）。

## 设计

| 项 | 规则 |
|---|---|
| 归属 | 用户自建模板带 `user_id`；内置模板 `user_id='builtin'` 且 `builtin=true` |
| 变量语法 | 正文里写 `{{name}}`，`variables` 存 `[{name,label,defaultValue}]` |
| 内置模板 | 启动即写入，只读；用户可复制为自有模板后修改 |
| 分类 | 写作 / 改写 / 摘要 / 翻译 / 大纲 / 代码 |

内置模板与用户模板同表同查询：列表按 `builtin desc, use_count desc` 排序，内置排前。

渲染规则：

| 情况 | 行为 |
|---|---|
| 变量有值 | 替换为传入值 |
| 变量无值但有默认值 | 替换为默认值 |
| 变量无值且无默认值 | 抛 `PROMPT_VARIABLE_MISSING`（8804） |
| 正文引用了未声明变量 | 保持原样不替换 |

## 契约

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/prompt/page` | 分页，含内置 |
| GET | `/api/v1/prompt/detail/{promptId}` | 详情 |
| POST | `/api/v1/prompt/create` | 新建 |
| POST | `/api/v1/prompt/update` | 更新（内置拒绝） |
| POST | `/api/v1/prompt/delete/{promptId}` | 删除（内置拒绝） |
| POST | `/api/v1/prompt/copy/{promptId}` | 复制为自有 |
| POST | `/api/v1/prompt/render` | 变量渲染，返回文本 |

## 关键流程

```
渲染
  ├─ 1 取模板并校验可见（自有或内置）
  ├─ 2 逐个变量取值：传入值 → 默认值 → 抛 PROMPT_VARIABLE_MISSING
  ├─ 3 正文做 {{name}} 字面替换
  ├─ 4 自有模板 use_count + 1
  └─ 5 返回渲染后文本

复制内置模板
  ├─ 1 读内置模板
  ├─ 2 以当前用户新建同名副本（标题加后缀"副本"）
  └─ 3 返回新模板 ID
```

## 取舍

| 选择 | 换来什么 | 代价 |
|---|---|---|
| 内置与自有同表 | 一次查询出全部，排序可控 | 内置行要处处判 `builtin` 守卫 |
| 变量用 `{{name}}` 字面替换 | 零依赖、用户可读可写 | 不做转义，正文含双花括号会误替换 |
| 渲染在服务端 | 前后端结果一致，可复用于 Agent | 每次渲染一次往返 |
| 使用次数只记自有模板 | 内置模板计数会被全体用户污染 | 热门内置模板无法排序 |

## 约束

- 内置模板修改与删除抛 `PROMPT_BUILTIN_READONLY`（8802）。
- 用户内模板标题唯一，重名抛 `PROMPT_TITLE_CONFLICT`（8803）。
- 正文上限 8000 字。
